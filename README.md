# Obsidian-templates
A repository for my obsidian setups people ask me to send them.
---
## Daily planner
to use the daily planner, in an empty vault you should download the folder Daily-note-setup, put the folder on the local you want, and **open** the obsidian on the Daily-note-setup folder (you can change the folder name!!)

## Chess study
to use the chess study platform, in an empty vault you should download the folder Chess-study-setup, put the folder on the local you want, and **open** the obsidian on the Daily-note-setup folder (you can change the folder name!!)

*in case of use on a vault with previous content, set an issue, and I'll readjust the README.md file to put instructions.
